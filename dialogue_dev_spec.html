01
产品架构总览
故事工作室
AI 辅助生成对话剧本，可逐行编辑台词、说话者、停顿标签。调用 Claude API 生成故事 JSON。
图文卡片编辑器
将剧本实时渲染为聊天界面风格的图文卡片，支持翻页预览，可导出每张卡片的 PNG / HTML。
配音工作台
调用 MiniMax 同步 TTS 逐句生成音频，支持音色设计、音色复刻，可单句重新生成或手动替换。
视频合成器
调用 MiniMax 异步 TTS 获取全文合并音频及精确时间戳，驱动本地波形渲染器生成 MP4 视频。
音色库
管理项目专属音色的 voice_id。支持系统音色选择、Voice Design 文字描述生成、音色克隆三种来源。
导出中心
统一管理项目所有产物：图文卡片包、逐句音频、合并音频、波形视频 MP4、脚本 JSON。

03
MiniMax API 集成规范
认证方式
# 所有请求统一使用 Bearer Token Authorization: Bearer $MINIMAX_API_KEY # Base URL https://api.minimaxi.com/v1
API Key 存储在服务端环境变量，不得出现在前端代码或客户端请求中。
同步语音合成（逐句配音）
speech-2.8-hd
POST/t2a_v2
用于配音工作台中单句生成，最大 10,000 字符，实时返回，适合交互式预览。
参数类型说明必填
modelstring固定使用 speech-2.8-hd必填
textstring台词文本，支持 <#0.3#> 停顿标签必填
voice_setting.voice_idstring系统音色 ID 或自定义 voice_id必填
voice_setting.speedfloat语速，范围 0.5~2.0，默认 1.0可选
voice_setting.volfloat音量，范围 0.1~10，默认 1.0可选
voice_setting.pitchint声调，范围 -12~12，默认 0可选
audio_setting.formatstring输出格式，使用 mp3可选
audio_setting.sample_rateint采样率，使用 32000可选
# 推荐请求体结构 { "model": "speech-2.8-hd", "text": "今天是您父亲<#0.3#>六十八岁生日。", "voice_setting": { "voice_id": "dialogue_ai_voice", // 项目存储的 voice_id "speed": 0.9, "vol": 1, "pitch": -1 }, "audio_setting": { "format": "mp3", "sample_rate": 32000 } }
异步语音合成（视频用，含时间戳）
speech-2.8-hd
异步接口支持返回句级时间戳，直接替代手动字幕标注，是视频合成流程的核心依赖。
POST/t2a_async_v2  →  获取 task_id
GET  /query/t2a_async_query_v2?task_id={id}  →  轮询进度
GET  /files/retrieve-content?file_id={id}  →  下载音频
参数说明
text全部台词按角色顺序拼接，每句之间用 \n 分隔
voice_setting与同步接口相同，此处使用主角色音色（助理）
timestamp_response设为 true，开启句级时间戳返回
audio_setting.formatmp3，与逐句音频格式一致
时间戳返回格式：每句文本对应 { "text": "…", "start_ms": 0, "end_ms": 3400 }， 直接转换为字幕 JSON 驱动波形视频渲染，无需人工标注。
# 异步任务轮询逻辑（伪代码） async def wait_for_tts(task_id): while True: res = GET /query/t2a_async_query_v2?task_id={task_id} if res.status == "Success": audio_url = res.file_id # 下载音频 timestamps = res.timestamps # 直接用于字幕 return audio_url, timestamps await sleep(2)
音色设计（Voice Design）
speech-2.8-hd
POST/voice_design
参数说明
description中文自然语言描述，如"普通话女声，清冷干净，语速平稳偏慢"
text用于试听的示例文本
voice_id自定义命名，项目内唯一，格式建议：项目名_角色名
modelspeech-2.8-hd
临时音色 48 小时内若未调用 TTS 会被删除。项目初始化完成后，需立即用该 voice_id 生成一句测试音频以激活保留。
音色快速复刻（Voice Clone）
speech-2.8-hd
POST/files/upload  →  purpose: "voice_clone"
POST/voice_clone
要求说明
音频格式mp3 / m4a / wav
音频时长最少 10 秒，最长 5 分钟
文件大小不超过 20MB
voice_id自定义，全平台唯一，命名规范：proj_{项目id}_{角色}
04
核心数据模型
// Project（项目） { id: string, // UUID title: string, // 项目名称 status: enum, // draft | voicing | done voices: { // 项目音色映射 [speaker_name]: { voice_id: string, source: enum, // system | design | clone settings: { speed, vol, pitch } } }, created_at: timestamp } // Line（台词行） { id: string, project_id: string, index: int, // 顺序编号 speaker: string, // 说话者名称 text_raw: string, // 原始文本（含停顿标签） text_clean: string, // 去掉标签后的纯文本（用于展示） audio_file: string, // 逐句音频路径（同步 TTS 生成） duration_ms: int, // 毫秒 status: enum // pending | generating | done | error } // VideoJob（视频任务） { id: string, project_id: string, tts_task_id: string, // MiniMax 异步 TTS 任务 ID merged_audio: string, // 合并音频文件路径 timestamps: array, // [{text, start_ms, end_ms, speaker}] video_file: string, // 最终 MP4 路径 status: enum // queued | tts_pending | rendering | done }
