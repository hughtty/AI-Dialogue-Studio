01 · 产品定位
我们在做什么
Dialogue 是一个面向中文内容创作者的 AI 故事工作室。
创作者输入一个故事方向，平台帮助他完成从剧本创作、图文卡片排版、AI 配音到波形视频生成的全流程——每一个环节都可以人工介入修改，最终一键导出适合不同平台分发的内容格式。

04 · API 接口规划
海螺模型接口预留清单
接口 模型 用途 调用时机 状态
POST /tts/generate 海螺 Speech-2.8-hd 逐句文字转语音，返回 MP3 + 时长 配音工作台 待接入
POST /tts/voice-design 海螺 Speech-2.8-hd 用自然语言描述生成专属音色，返回 voice_id 项目初始化 待接入
POST /video/generate 海螺 Video API 提交合并音频，生成带波形动效的背景视频 视频导演台 待接入
GET /video/status 海螺 Video API 轮询视频生成任务进度，返回进度百分比 视频导演台 待接入
POST /llm/story 内部 Claude API 根据主题和参数生成对话剧本 JSON 故事工作室 已可用

06 · 设计原则
产品的三条底线
可介入
AI 生成的每一个环节都必须可以被人工修改和替换。AI 是助手，不是决策者。
可预览
在任何生成操作执行前，创作者都能看到将要产出的内容是什么样的。没有黑盒。
可导出
每个步骤的产物都是独立可用的文件，不绑定平台。创作者随时可以带着资产离开。
